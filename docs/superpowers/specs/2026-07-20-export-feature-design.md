# Export Feature Design Spec

**Date:** 2026-07-20
**Status:** Draft
**Scope:** PDF and HTML report export from PerfLens dashboard

## Overview

Add export functionality to PerfLens that generates PDF and HTML reports from the current dashboard analysis. The export captures all visible dashboard sections as static images (for charts) and structured text (for action items), then assembles them into a downloadable report.

All processing is client-side using `jsPDF` and `html2canvas`, consistent with PerfLens's offline-capable, privacy-first architecture.

## Architecture

### New Dependencies

- `jspdf` — PDF document generation
- `html2canvas` — DOM-to-canvas screenshot capture

### New Files

```
src/app/core/services/
  export.service.ts           # Orchestrates the export pipeline
  section-capture.service.ts  # Captures dashboard sections as images

src/app/features/dashboard/
  export-dialog.component.ts  # Modal overlay for format selection + progress
```

### Component Interaction

1. User clicks the **Export** button in the dashboard nav bar
2. `ExportDialogComponent` opens as a modal overlay
3. User selects format (PDF or HTML) and clicks "Generate"
4. `ExportService` orchestrates the capture-and-assemble pipeline
5. Progress updates stream to the dialog via an Observable
6. On completion, a download link is presented

## Section Capture Strategy

### Section Registry

The `ExportService` maintains a registry of capturable sections, keyed by file format:

| File Format    | Sections (in order)                                                      |
|----------------|--------------------------------------------------------------------------|
| perf-trace     | Score Cards, Action Items, Flamegraph, Timeline, Network Waterfall       |
| heap-snapshot  | Score Cards, Action Items, Treemap, Object Breakdown, Detached DOM       |
| cpu-profile    | Score Cards, Action Items, Flame Chart, Hot Functions, V8 Deopts (if any)|

### Capture Process Per Section

1. Temporarily un-hide the section's tab panel (set `[hidden]="false"`)
2. Wait for Angular rendering to settle: call `afterNextRender()` to wait for the next change-detection + DOM paint cycle. If the section contains async-rendered content (e.g., heap treemap canvas), add a secondary 200ms `setTimeout` guard before capturing.
3. Call `html2canvas()` on the section's host element with `{ useCORS: true, backgroundColor: '#0d1117' }` (dark theme background)
4. Store the resulting canvas as a PNG data URL along with dimensions
5. Restore the section's original hidden state

### Capture Output

```typescript
interface CapturedSection {
  id: string;        // e.g., 'flamegraph', 'action-items'
  title: string;     // Human-readable: 'Flamegraph', 'Action Items'
  imageDataUrl: string;
  width: number;
  height: number;
}
```

### Special Handling

- **Action Items:** Captured as an image like other sections, but also exported as structured text/HTML table in the final document for searchability.
- **Score Cards:** Captured as image. Metric values are also included as text in the report header.
- **Canvas elements (flamegraph, treemap):** `html2canvas` handles `<canvas>` elements natively.
- **SVG charts (D3 flame chart):** `html2canvas` renders inline SVG. External stylesheets applied to SVG must be inlined before capture.

## PDF Assembly

### Document Setup

- **Page size:** A4 landscape (297mm × 210mm) — better for wide charts
- **Margins:** 15mm all sides
- **Font:** Helvetica (built into jsPDF)

### Page Layout

**Page 1 — Cover / Summary:**
- PerfLens logo text ("⚡ PerfLens")
- File name, file size, analysis date
- Overall metric scores as a summary table (LCP, CLS, INP, etc., depending on file type)

**Subsequent Pages — One Section Per Page:**
- Section title as a header
- Section screenshot scaled to fit the page width (maintaining aspect ratio)
- If the screenshot is taller than the available page height, it is split across multiple pages with overlap

**Action Items Page:**
- Rendered as a structured table using jsPDF's table API (not just a screenshot)
- Columns: Severity icon, Title, Description, Category
- Color-coded severity: red (critical), orange (warning), blue (info)

**Footer:**
- "Generated by PerfLens • {ISO date} • Page {X} of {Y}"

### Color Scheme

PDF uses a light background (#ffffff) with dark text for print readability. Section screenshots retain their dark theme appearance.

## HTML Assembly

### Structure

Self-contained single `.html` file with:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>PerfLens Report — {fileName}</title>
  <style>/* inlined styles */</style>
</head>
<body>
  <header><!-- PerfLens branding, file info, date --></header>
  <section id="scores"><!-- Metric summary table --></section>
  <section id="action-items"><!-- HTML table --></section>
  <section id="flamegraph"><!-- <img src="data:image/png;base64,..."> --></section>
  <!-- ... more sections ... -->
  <footer>Generated by PerfLens • {date}</footer>
</body>
</html>
```

### Styling

- Minimal inlined CSS (no external dependencies)
- Dark theme by default, matching the app
- `@media print` override switches to light background for printing
- Responsive: sections stack vertically, images scale to container width

### Action Items

Rendered as an actual HTML `<table>` (searchable, selectable, copyable) in addition to the screenshot.

## Export Dialog Component

### UI States

1. **Format Selection:**
   - Two large buttons: "PDF Report" and "HTML Report"
   - Brief description under each
   - "Cancel" button

2. **Progress:**
   - Progress bar with step label: "Capturing {SectionName}... (2/5)"
   - Percentage indicator
   - "Cancel" button (aborts and closes)

3. **Complete:**
   - "✅ Report ready!"
   - "Download" button (triggers browser download)
   - "Close" button

4. **Error:**
   - Error message
   - "Try Again" / "Close" buttons

### Styling

- Modal overlay with backdrop blur
- Centered card matching existing PerfLens dark theme
- Accessible: focus trap, escape to close, aria-labels

## Dashboard Integration

### Nav Bar Change

Enable the currently-disabled "Export" button in `DashboardComponent`'s nav:

```html
<button (click)="showExportDialog.set(true)" class="hover:text-white transition-colors">Export</button>
```

### Export Dialog Rendering

Add the dialog component inside the dashboard template, conditionally rendered:

```html
@if (showExportDialog()) {
  <app-export-dialog
    [result]="result()"
    [fileFormat]="fileFormat()"
    [heapSnapshot]="heapSnapshot()"
    [cpuProfile]="cpuProfile()"
    (close)="showExportDialog.set(false)"
  />
}
```

## Progress & Cancellation

The `ExportService.export()` method returns an `Observable<ExportProgress>`:

```typescript
interface ExportProgress {
  phase: 'capturing' | 'assembling' | 'complete' | 'error';
  currentSection?: string;
  currentStep: number;
  totalSteps: number;
  percentage: number;
  result?: Blob;      // Present when phase === 'complete'
  error?: string;     // Present when phase === 'error'
}
```

Cancellation is supported via RxJS unsubscription — the service checks an AbortSignal between section captures.

## Testing Strategy

- **Unit tests** for `ExportService` — mock `html2canvas` and `jsPDF`, verify correct section ordering and assembly logic
- **Unit tests** for `SectionCaptureService` — mock `html2canvas`, verify it cycles through sections correctly
- **Component tests** for `ExportDialogComponent` — verify UI states, button interactions, progress display
- **Integration test** — a smoke test that exercises the full pipeline with a small test trace (may need to run in a browser environment)

## File Size Considerations

- A typical perf trace report with 5 sections produces ~2-5MB of PNG data
- PDF output: ~3-6MB (images are embedded)
- HTML output: ~3-7MB (base64 encoding adds ~33% overhead)
- Large heap treemaps or flamegraphs could push individual section images to 1-2MB
- No compression is applied to images in the initial implementation; JPEG conversion for large sections is a future optimization

## Out of Scope

- Custom report templates or branding
- Scheduled/automated exports
- Cloud-based export or sharing (this is a separate "Share" feature)
- Comparison report (diff two traces) — separate feature
- Export of raw data (JSON dump of analysis results)
